What it can answer

단순 가격 조회보다,
시장 맥락을 묻는 데 적합합니다.

단지명과 지역을 안정적으로 해석하고, 동일 전용면적·동일 기간의 데이터를 기준으로 비교합니다. 계산은 도구가 수행하고 AI는 그 근거를 설명합니다.

지역 시장 펄스

거래량, 신고가, 회복률과 표본 신뢰도를 함께 보며 “지금 무엇이 달라졌는가”를 요약합니다.

“마포구 전용 84㎡ 중 전고점 회복률과 거래량이 함께 오른 단지를 보여줘.”
사실최근 30일 거래 6건원천 데이터
파생 지표거래량 모멘텀 2.0산식 적용
해석단기 유동성 회복 후보조건부 설명

최근 실거래와 회복률

최신 거래, 기간 중위가, 역대 최고가를 분리하고 표본 수와 취소 거래 반영 여부까지 표시합니다.

동일 면적 단지 비교

서로 다른 평형을 섞지 않고 같은 전용면적·기간·필터·산식 버전으로 단지를 비교합니다.

관심 단지 변경 브리핑

신규 신고, 취소·정정, 신고가, 거래량 변화 등 관심 단지에서 달라진 내용만 골라 요약할 수 있습니다.

전세가율과 추정 갭

같은 면적·표본 기간의 매매와 전세 중위값을 사용하며, 실제 동일 매물 쌍이 아닌 값은 “추정”으로 구분합니다.

Evidence-first workflow

AI가 가격을 외우는 대신,
필요한 순간에 데이터를 호출합니다.

자연어 질문을 곧바로 답하지 않습니다. 대상을 해석하고, 허용된 원천에서 거래를 조회한 뒤, 버전이 고정된 산식으로 지표를 계산합니다.

01

질문 해석

지역·단지·면적·기간·거래 유형을 구조화합니다.

02

MCP 도구 호출

모호한 단지명을 해소하고 최신 신고 거래를 조회합니다.

03

지표 계산

회복률·거래량·전세가율 등을 결정론적으로 계산합니다.

04

근거 설명

사실, 파생 지표, 해석과 주의사항을 분리해 답합니다.

핵심 원칙: 최신성이 필요한 질문을 모델 내부 지식으로 추측하지 않으며, 취소·정정·표본 부족과 데이터 기준 시각을 숨기지 않습니다.

Who it is for

아파트 데이터를 “조회”에서
“설명 가능한 도구”로 바꾸려는 사람들.

완성된 투자 추천 서비스가 아니라, 신뢰 가능한 부동산 AI를 설계하기 위한 기반 패키지입니다. 개인 프로젝트부터 사내 도구까지 범위를 확장할 수 있습니다.

관심 단지 · 단지 비교

Agent · MCP · API

리서처·콘텐츠 제작자

리서치 · 브리핑 · 시각화

Build with MIT

코드를 가져가서,
당신의 부동산 AI로 확장하십시오.

MIT 라이선스 아래에서 사용·수정·배포·재라이선스·상업 활용이 가능합니다. 저작권 고지와 라이선스 문구는 유지해야 하며, 데이터 원천의 별도 이용 조건은 각각 확인해야 합니다.

사용 수정 배포 상업 활용 서브라이선스
BUILD 01

관심 단지 레이더

신규 실거래, 취소·정정, 신고가와 거래량 변화를 매일 요약하는 개인 브리핑 서비스.

BUILD 02

지역 시장 대시보드

구·동·면적별 거래량, 회복률, 전세가율과 데이터 신뢰도를 시각화하는 웹 대시보드.

BUILD 03

부동산 상담 보조 AI

고객 질문에서 단지와 조건을 해석하고, 담당자가 확인할 근거 자료를 빠르게 정리하는 사내 도구.

BUILD 04

리서치·콘텐츠 자동화

지역별 시장 변화와 지표를 정기적으로 분석해 보고서, 뉴스레터, 콘텐츠 초안을 만드는 파이프라인.

라이선스 안내는 이해를 돕기 위한 요약입니다. 실제 사용·배포 시 저장소의 LICENSE 원문과 각 데이터 제공자의 이용 조건을 확인해야 합니다.

문서 모음이 아니라,

Trust by design

답변의 문장보다,
답변이 만들어지는 규칙을 설계합니다.

부동산 데이터는 신고 지연, 취소, 면적 혼합과 표본 부족으로 쉽게 왜곡됩니다. 이 프로젝트는 그러한 한계를 숨기지 않는 것을 기본 동작으로 삼습니다.

Freshness

“최신”의 시각을 표시합니다.

계약일, 원천 데이터 갱신 시각, 시스템 수집 시각을 구분해 사용자가 데이터의 시간 기준을 확인할 수 있게 합니다.

Comparability

비교 기준을 맞춥니다.

동일 전용면적, 동일 기간, 동일 필터와 산식 버전으로 비교하며 서로 다른 평형을 임의로 한 지표에 섞지 않습니다.

Boundaries

분석과 권유를 구분합니다.

가격 상승이나 수익을 보장하지 않으며, 투자·감정평가·대출 승인·세무 판단을 확정하는 서비스로 표현하지 않습니다.

한국 아파트 데이터에
설명 가능한 AI 인터페이스를 더해보십시오.

저장소에서 PRD, MCP 도구 명세, 완성형 SKILL.md, PostgreSQL 스키마와 평가 세트를 확인할 수 있습니다.
