```markdown
## 해석한 조건

- 거래 유형:
- 지역:
- 예산:
- 면적:
- 필수 조건:
- 선호 조건:
- 미확인 처리:

## 추천 결과

### 1위 · 단지명

- 적합도: 00.0 / 100
- 데이터 신뢰도: 00.0 / 100
- 기준 가격:
- 최근 거래일:
- 유효 거래 수:
- 추천 이유:

- 미확인 항목:
```

## 2. 필수 표현

- “입력한 조건 기준 적합도”
- “최신 신고·공개된 실거래”
- “광고가격은 호가”
- “원문에서 현재 상태 확인 필요”
- 데이터 기간·표본 수
- 미확인 항목

## 3. 금지 표현

- 최고의 아파트
- 무조건 사야 하는 단지
- 현재 확정 시세
- 실매물 보장
- 대출 승인 가능
- 향후 상승 확정

## 5. 사실 분리

```text
공식 사실 → 공공 API 레코드
파생 지표 → 산식과 버전이 있는 계산
추천 점수 → 프로필과 candidate facts의 결정론적 함수
AI 해석 → 의미·트레이드오프 설명
원문 링크 → 제3자 플랫폼 확인 경로
```

## 6. 데이터 부족

- 표본 0: 가격 표시하지 않음
- 표본 1: 단일 거래 경고
- 현재 월: 신고 미완결 경고
- enrichment 없음: “미확인”
- listing metadata 없음: 링크만 표시

## 7. 부분 실패

성공한 지역과 실패한 지역을 분리합니다. 원천 하나가 실패해도 다른 원천에서 성공한 것처럼 위장하지 않습니다.
